## 🚀 Passos Imediatos

### 1. Instalar Dependências

```bash
cd c:\Projetos\QA-Tools
npm install
```

### 2. Testar Localmente

```bash
npm run dev
```

Abra http://localhost:5173 e teste todas as ferramentas:
- [ ] Gerador de Dados
- [ ] Validador de API
- [ ] Conversor de Arquivos
- [ ] Testador de Regex
- [ ] Checklist de Testes

### 3. Verificar Build de Produção

```bash
npm run build
npm run preview
```

### 4. Criar Repositório no GitHub

1. Vá em https://github.com/new
2. Nome: `QA-Tools`
3. Descrição: `Ferramentas práticas para profissionais de QA`
4. Visibilidade: Público
5. Não inicialize com README (já temos)
6. Crie o repositório

### 5. Configurar Git Local

```bash
git init
git add .
git commit -m "feat: implementação inicial do QA Tools"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/QA-Tools.git
```

### 6. Atualizar URLs no Código

Substitua `yourusername` pelo seu usuário do GitHub nos arquivos:

**Arquivos para atualizar:**
- [ ] `package.json` (homepage, repository, bugs)
- [ ] `README.md` (links do GitHub)
- [ ] `vite.config.js` (base: '/QA-Tools/')
- [ ] `src/main.jsx` (basename="/QA-Tools")
- [ ] `src/components/Layout/Header.jsx`
- [ ] `src/components/Layout/Footer.jsx`
- [ ] Todos os arquivos .md com links

**Busque e substitua:**
```
yourusername → SEU-USUARIO-GITHUB
your.email@example.com → seu-email@dominio.com
```

### 7. Fazer Push

```bash
git push -u origin main
```

### 8. Configurar GitHub Pages

1. Vá em: https://github.com/SEU-USUARIO/QA-Tools/settings/pages
2. Source: **GitHub Actions**
3. Aguarde o workflow executar (~ 2-3 minutos)
4. Acesse: https://SEU-USUARIO.github.io/QA-Tools
